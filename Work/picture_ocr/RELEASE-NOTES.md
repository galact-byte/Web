## 🛠️ 修复与优化

- 修复项目列表中多个互不相关的“单系统项目”被错误合并显示成同一个“未分组 / 单系统项目”分组的问题；现在每个单系统项目各自独立成行。
- 导入数据包不再弹出系统 alert：导入过程中在弹窗内显示进度条，完成后在同一弹窗内以绿色“导入完成”卡片展示结果，失败时显示红色错误提示并可直接重试。
- 全面替换浏览器原生弹窗：导出、保存、删除、加载等提示统一改为界面右上角的轻提示（toast），非阻塞、可堆叠、自动消失，不再打断操作。

## 📦 下载与使用

- **Web 静态版**：下载本 Release 附带的 web ZIP，解压后双击“启动测评证据采集工具.bat”，运行期间保持 PowerShell 窗口开启。
- **Windows 客户端**：下载本 Release 附带的 `.exe` 便携版后双击运行，放在任意位置即可，无需覆盖旧版本。
- 纯前端更新，数据格式不变，无需迁移；数据保存在 `%APPDATA%\picture_ocr`，升级不影响已采集内容。
