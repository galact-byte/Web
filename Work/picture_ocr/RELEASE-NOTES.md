# 测评证据采集工具 v0.8.1

## 🛠️ 修复与优化

- 多系统项目恢复列表内直接展开／收起，可同时查看多个项目，不再需要进入项目后返回；「多系统项目／独立系统」分类页签继续保留。
- 放大展开箭头和点击区域，点击项目标题即可展开。项目名称、单位与系统数量集中展示，组内系统使用独立表头，长名称和资产数显示更清楚。
- 去掉页签下重复的分类标题及多余工具栏；相同单位不再逐行重复，不同单位仍保留。全选并入表头，选中系统后才显示批量删除。
- 从工作区返回时恢复展开状态、搜索条件和滚动位置；全部收起后刷新列表仍保留选择。搜索直接展示匹配系统，清除搜索后恢复原展开状态。
- 新建项目或添加系统后自动展开并定位。保存成功但列表刷新失败时可重试刷新，避免重复创建。
- 批量选择限定在单个项目内，收起项目、切换页签或搜索后清空选择；项目手机采集始终包含整个项目，不受搜索结果影响。

## 🔄 兼容性说明

- 网页版与 Windows 桌面版同步更新。
- 数据库版本、已有系统归属和图片存储格式保持不变，无需迁移数据。
- 单系统组、空组和项目组记录缺失的系统仍保留入口；列表继续只读取轻量摘要。

## 下载与使用

- Windows 桌面版：下载本 Release 的便携版 `.exe`。
- 网页版：下载 ZIP，解压后运行“启动测评证据采集工具.bat”，继续使用原来的浏览器和访问地址。
