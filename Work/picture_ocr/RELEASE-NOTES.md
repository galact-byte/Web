## ✨ 新增功能

- **照片与项目分开存放，拍照不再越用越卡**：以前每加一张照片，程序都要把整个项目（包括里面已有的全部照片）重新写一遍，项目越大越慢，几十张图之后就会出现“转圈、保存超时、拍着拍着卡死”。本版本把照片单独存放，加照片时只写这一张，项目本身只记录一条引用。
  - 实测：一个约 480MB 的库、单个系统里已有 6 张 8MB 大图时，再加一张照片从选中到写入完成约 **0.08 秒**（旧版需要重写几十 MB 的整份项目）。
  - 打开项目、返回列表、切换系统也随之变快，照片按需加载，不再一次性堆进内存。
- **老项目自动后台整理**：升级后首次打开软件，程序会在后台逐个把旧项目里的照片搬到新的存放方式，**一个项目搬完立刻记录进度**，中途关闭软件也不用重来，下次打开会接着搬。整理期间照片照常查看、照常拍照。
- **存储设置里可查看整理进度**：进入「存储设置」可以看到已整理项目数、待整理数量；如果有项目整理失败，可以点击「重试」单独再跑一次，不影响其他项目。

## 🛠️ 修复与优化

- **修复手机上传与电脑端互相覆盖导致的丢图**：以前手机传上来的照片和电脑端的自动保存都会整份覆盖项目，谁后写谁赢，时序不巧时手机刚传的照片会被电脑端覆盖掉。现在写入照片时直接改数据库里的最新内容，两边同时写也不会互相冲掉。
- **报告与数据包导出保持完整原图**：导出 Word 报告、`.zip` 数据包、`.evidence` 加密采集包时会自动补齐照片原始数据，内嵌的仍是完整分辨率原图。
- **存量图片瘦身、数据包导入**同样适配新的存放方式；取不到照片数据的会明确计入失败并提示，不再静默跳过。

## 🔄 兼容性说明

- **升级后老项目和照片不会丢**：
  - 数据库升级本身只新建存放区，不动任何一条已有数据；
  - 搬迁按项目逐个进行，每张照片都是「先写入新位置 → 立刻读回校验 → 全部校验通过，才从项目里移除旧副本」，任何一步失败该项目会整体回滚、保持原样，并记录下来供重试；
  - 未整理完的项目仍按老方式读取，整理期间新旧两种形态可以共存。
  - 发布前已用约 480MB、60 张大图的模拟库完成整套演练：60 张照片逐条比对内容完全一致，0 失败、0 丢失。
- **本版本升级后不建议再退回 0.6.x**：旧版本不认识新的照片存放区，回退后已整理项目的照片将无法显示（数据仍在库里，重新安装 0.7.0 即可恢复）。如需保险，可在升级前先用「导出数据包」备份重要项目。
- 桌面客户端与网页版均已覆盖，0.6.3 的关窗保护（保存未完成时拦截关闭）继续保留。

## 📦 下载与使用

- **Windows 客户端**：下载本 Release 附带的 `.exe` 便携版后双击运行，放在任意位置即可，无需覆盖旧版本。
- **Web 静态版**：下载本 Release 附带的 web ZIP，解压后双击“启动测评证据采集工具.bat”，运行期间保持 PowerShell 窗口开启。
- 首次启动后如果项目较多，请让软件在前台运行一会儿，等存储设置里的整理进度跑完再进行大批量拍照。
