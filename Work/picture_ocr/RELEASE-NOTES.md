## 🛠️ 修复与优化

- **修复“项目列表里少了项目”**：0.6.1 虽然让卡住的数据库能重新打开，但升级时读不出内容的个别记录会被直接跳过，跳过后那个项目就再也不出现在列表里，而且没有任何提示。本版本改为**逐条核对**：数据库里有几个项目文档、列表里就必须有几条，缺的会自动补回列表，打开软件即可看到找回的项目（找回时会有一次提示）。反过来，列表里残留的失效条目（点开会报错的“幽灵项目”）也会被清理。
- **保存失败不再悄悄发生**：以前项目自动保存失败只写在后台日志里，界面毫无反应，刚拍的照片其实只留在内存中，关掉窗口就没了。现在保存失败会立刻弹出醒目提示，明确告知“请勿关闭窗口并重试”，并记入诊断包。手机局域网上传写入失败同样会记录在电脑端。
- **修复可能清空项目的严重隐患**：打开项目时若读取超时或失败，旧版本会用一个空白项目顶替并在半秒后自动保存，**把原有内容覆盖成空的**。现在读取失败时会停止自动保存并提示重新打开，绝不会覆盖已有数据。
- **大项目不再被误判为保存失败**：项目内容很多（图片多、体积大）时，读写整份项目需要的时间更长，旧的超时上限过短会中途报错。本版本为整份项目的读写放宽了时限，避免正常保存被误报为失败。

## ✨ 新增功能

- **存储设置里新增「存储自检」**：可随时查看“项目文档 N 条 / 列表索引 N 条 / 项目组 N 个”，数量不一致会标红提醒；点「立即自检并修复」即可把漏掉的项目重新加回列表（不会删除任何图片）。
- **诊断包内容更完整**：新增各数据表的真实条数、最近一次自检修复结果、以及项目清单（系统名、图片数、更新时间）。若有记录确实读不出内容，诊断包会列出其编号，便于技术支持定位。

## 🔄 兼容性说明

- 本版本只做核对与补齐，**不会删除项目或图片**；清理的仅是指向已删除项目的失效列表条目。
- 数据量大的电脑首次打开会多花几秒完成一次核对，之后恢复秒开。
- 桌面客户端与网页版使用同一套存储逻辑，两端均已修复。
- 升级后请使用本版本或更新版本打开数据，不要再退回旧版本打开同一份数据。

## 📦 下载与使用

- **Windows 客户端**：下载本 Release 附带的 `.exe` 便携版后双击运行，放在任意位置即可，无需覆盖旧版本。
- **Web 静态版**：下载本 Release 附带的 web ZIP，解压后双击“启动测评证据采集工具.bat”，运行期间保持 PowerShell 窗口开启。
