## 🛠️ 修复与优化

- **修复“刚拍的照片关掉窗口就没了”**：项目里的图片越多，保存一次要写入的数据就越多，大项目可能需要十几秒甚至更久。旧版本在保存还没写完时关闭窗口，正在写入的内容会被直接中断，**刚拍的那张照片就此丢失，而且没有任何提示**。本版本在关闭前会先检查是否还有没保存完的内容：
  - **桌面客户端**：会弹出“正在保存”对话框，可选择“等保存完成后退出”（写完自动关闭）、“取消关闭”，或在确实需要时选择“仍然退出”。
  - **网页版**：浏览器会弹出离开确认，提醒仍有内容正在保存。
- **界面新增「正在保存，请勿关闭窗口」提示条**：保存期间会在右下角显示，并标注还有几项待写入。以前保存慢时界面没有任何反馈，容易被误认为卡死而强制关闭，反而造成丢失。

## 🔄 兼容性说明

- 本版本不改变数据存储结构，可与 0.6.2 混用，数据完全兼容。
- 桌面客户端与网页版均已覆盖。
- **仍然建议**：看到“正在保存”提示时请等待其消失再关闭窗口；若弹出保存失败提示，请按提示重试，不要直接关闭。
- 图片较多的项目保存变慢的**根本原因**（每加一张照片都要重写整个项目）将在下一个大版本中彻底解决，本版本先确保不会因为关窗而丢数据。

## 📦 下载与使用

- **Windows 客户端**：下载本 Release 附带的 `.exe` 便携版后双击运行，放在任意位置即可，无需覆盖旧版本。
- **Web 静态版**：下载本 Release 附带的 web ZIP，解压后双击“启动测评证据采集工具.bat”，运行期间保持 PowerShell 窗口开启。
