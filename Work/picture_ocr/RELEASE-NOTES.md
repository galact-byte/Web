## ✨ 新增功能

- **图片入库自动压缩**：手机拍照原图往往有 6-8MB，100 张就能撑到几百 MB，导致返回项目、导出报告卡顿。现在**所有新图在入库前自动等比压缩**（长边压到 1920px、JPEG 高质量），单张从数 MB 降到几百 KB，覆盖三处入口——手机局域网上传、手机网页相机拍照、电脑端拖拽/粘贴/选择导入。手机上传还因此只走压缩后的小图，**网络传输更快**。
- **一键「压缩图片」瘦身现有系统**：针对升级前已经拍进去的大图，「项目管理中心」每个系统行新增**「压缩图片」**按钮，可把该系统里**已存的旧图批量就地压缩**。实测一个 444MB 的系统压缩后降到约 44MB（约 1/10），返回项目和导出报告随之明显变流畅。

## 🛠️ 修复与优化

- **解决大图卡顿**：手机大量取证照片导致的「返回项目卡住」「导出报告卡住」得到根治，卡顿来自把数百 MB 图片整包读入内存与嵌入报告，压缩后体积大幅下降。
- **导出报告依旧清晰**：压缩参数经真实「拍屏幕」证据图验证，事件日志、时间戳、明细文字均清晰可读，报告观感不受影响。
- **只减不增、智能跳过**：压缩仅在能变小时才替换，已经足够小的截图自动跳过、不会二次劣化；批量压缩可重复执行，不会越压越糊。
- **方向正确**：保留照片 EXIF 方向信息，压缩后不会出现横竖颠倒。

## 📦 下载与使用

- **Web 静态版**：下载本 Release 附带的 web ZIP，解压后双击“启动测评证据采集工具.bat”，运行期间保持 PowerShell 窗口开启。
- **Windows 客户端**：下载本 Release 附带的 `.exe` 便携版后双击运行，放在任意位置即可，无需覆盖旧版本。
- **给现有系统瘦身**：升级后打开「项目管理中心」，在需要瘦身的系统行点「压缩图片」，确认后等待完成提示（会显示压缩张数与节省体积）。该操作会改写已存图片且不可撤销，建议先导出一份数据包备份。

## 🔄 兼容性说明

- 数据格式与存储位置不变，已采集内容、既有项目与项目组不受影响，无需迁移。
- 入库压缩只对**升级后新拍/新导入的图片**生效；**升级前已存的旧图**需在系统行点一次「压缩图片」才会瘦身。
- Web 静态版与 Windows 客户端行为一致；压缩全部在本地完成，不改变局域网采集的上传与校验协议。
