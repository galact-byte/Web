## 🛠️ 修复与优化

- **修复升级后项目全部“消失”、列表加载失败的问题**：部分用户升级到 0.6.0 后，打开软件顶部报「加载项目列表失败：Version change transaction was aborted…」与「Cannot read properties of null (reading 'id')」，项目管理中心显示 0 个项目组、0 个系统，实际数据打不开。原因是 0.6.0 首次打开时的数据库升级会顺带整理一份“轻量目录”，一旦历史数据里存在个别异常记录，整理过程报错会连带把整次升级回滚，导致数据库卡在旧版本、每次打开都重复失败。**本次修复后升级不再因个别异常记录而整体失败**，异常记录会被自动跳过，其余项目全部照常显示。
- **卡住的数据库可自愈**：已经出现上述错误的电脑，装上本版本后无需清库、无需任何手动操作，打开即自动完成升级并恢复全部项目与图片。
- **升级更稳**：数据库升级过程加了兜底保护与占用提示（若有其他窗口正打开同一份数据会给出明确提示），避免再出现“升级中途失败又反复重试”的死循环。

## 🔄 兼容性说明

- **数据不会丢失**：出现该错误时数据只是暂时读不到，并未被删除；升级修复后会原样恢复。
- 已采集内容、既有项目与项目组不受影响；数据量大时首次打开可能稍慢几秒完成一次目录整理，之后恢复秒开。
- 升级后请使用本版本或更新版本打开数据，不要再退回旧版本打开同一份数据。

## 📦 下载与使用

- **Windows 客户端**：下载本 Release 附带的 `.exe` 便携版后双击运行，放在任意位置即可，无需覆盖旧版本。
- **Web 静态版**：下载本 Release 附带的 web ZIP，解压后双击“启动测评证据采集工具.bat”，运行期间保持 PowerShell 窗口开启。
