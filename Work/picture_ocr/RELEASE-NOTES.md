## 🛠️ 修复导出数据包失败

- 修复点击“导出数据包”时报错 `导出失败：Failed to fetch` 的问题。此前含较多实拍大图的系统在导出时，程序把图片从 base64 还原为文件的方式，在桌面客户端（`file://` 环境读取大图）和网页版（CSP 限制 `data:` 请求）下都会失败，导致整包导出中断。
- 现改为在本地直接解码 base64，不再发起网络请求，导出不再受图片大小、运行环境或安全策略影响。加密采集包（`.evidence`）导出走的是同一段逻辑，一并修复。

## 🔄 兼容性说明

- 纯前端修复，数据格式完全不变，无需迁移；现有项目、分类、资产、检查项与截图全部兼容。
- 桌面客户端升级不会影响已采集的数据：数据保存在当前 Windows 用户目录（`%APPDATA%\picture_ocr`），与程序版本和存放位置无关，替换新版 exe 后原有项目与图片仍在。
- 建议升级前先备份该数据目录作为兜底；请在同一 Windows 账户下运行，避免看不到原有数据。
- Web 静态版与 Windows 客户端为同一套实现，刷新网页或替换客户端后即生效。

## 📦 下载与使用

- **Web 静态版**：下载本 Release 附带的 web ZIP，解压后双击“启动测评证据采集工具.bat”。运行期间请保持 PowerShell 窗口开启。
- **Windows 客户端**：下载本 Release 附带的 `.exe` 便携版后双击运行，放在任意位置即可，无需覆盖旧版本。
