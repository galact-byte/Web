## 🛠️ 修复与优化

- **导入数据包现在会压缩图片**：0.5.4 只压了拍照/选文件，ZIP / `.evidence` 导入仍按原图入库。一份 444MB、121 张的证据包导进去还是原体积，返回项目和导出报告依旧卡。0.5.5 导入时对每张图走同一套压缩（长边 1920px、JPEG 高质量）。
- **「压缩图片」不再误报「已足够小」**：桌面版和 Web 的安全策略会拦截 `fetch(data:…)`，旧版存量压缩因此静默失败，再把失败当成「所有图片都已足够小」。现已改为本地解码；失败会明确提示未能处理的张数，并保留原图。
- **已压缩的图不会再被来回压**：长边已经是 1920 的 JPEG 不再二次编码，避免点一次只省十几字节。结果会显示「共扫描 N 张」，方便确认扫到的是不是那个大系统。

## 📦 下载与使用

- **Web 静态版**：下载本 Release 附带的 web ZIP，解压后双击“启动测评证据采集工具.bat”，运行期间保持 PowerShell 窗口开启。
- **Windows 客户端**：下载本 Release 附带的 `.exe` 便携版后双击运行，放在任意位置即可，无需覆盖旧版本。
- **给 0.5.4 已导入的大包瘦身**：Web 与桌面数据不同源。若某份数据导入时还没压缩，升级后在「项目管理中心」对应系统行点一次「压缩图片」。该操作会改写已存图片且不可撤销，建议先导出一份数据包备份。

## 🔄 兼容性说明

- 数据格式与存储位置不变，已采集内容、既有项目与项目组不受影响，无需迁移。
- 新导入的数据包会在入库时自动压缩；升级前已经按原图入库的数据，需点一次「压缩图片」才会瘦身。
- Web 静态版与 Windows 客户端行为一致；压缩全部在本地完成。
