## 🛠️ 修复与优化

- **修复导出 Word 报告里截图发虚、变形**：此前每张证据图被强制塞进固定 4:3 的小框，宽终端/配置截图会被拉伸变形，字也小、放大就糊。现在每张图**独占一行、铺满正文宽度、按原始比例显示**；原图仍是全分辨率无损嵌入，放大依旧清晰可读。
- **优化报告文件名**：未填写“项目名称”时，改用 `单位名_系统名` 命名，不再出现“未命名项目_xxx”这种难看的前缀；填了项目名则仍用 `项目名_系统名`。

## 📦 下载与使用

- **Web 静态版**：下载本 Release 附带的 web ZIP，解压后双击“启动测评证据采集工具.bat”，运行期间保持 PowerShell 窗口开启。
- **Windows 客户端**：下载本 Release 附带的 `.exe` 便携版后双击运行，放在任意位置即可，无需覆盖旧版本。
