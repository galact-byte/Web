## 🛠️ 修复与优化

- **修复项目多、图片多以后卡死的问题**：当一个项目组下有多个系统、累计几百张图片时，打开软件会卡在「正在加载项目列表…」，新建项目也会卡在「保存中…」转圈不动。原因是每次刷新列表都把所有图片一起读进内存又复制一遍。现在列表改为只读取轻量目录信息（项目名、系统、图片张数等），**不再搬运图片本身**，加载速度和图片多少无关，几百张图也能秒开。
- **不再无限转圈**：万一数据库真的被占用或异常，操作会在超时后弹出明确提示，而不是永远卡住让人以为死机。

## ✨ 新增功能

- **一键导出诊断包**：在「存储设置」里新增「导出诊断包」按钮。遇到卡顿、报错或异常时，点一下会导出一个 JSON 文件（包含最近的错误记录、软件版本、存储用量、项目与图片数量），把它发给技术支持即可快速定位问题，不用再靠猜和反复截图描述。软件现在也会自动记录最近的错误，导出时一并带上。

## 📦 下载与使用

- **Web 静态版**：下载本 Release 附带的 web ZIP，解压后双击“启动测评证据采集工具.bat”，运行期间保持 PowerShell 窗口开启。
- **Windows 客户端**：下载本 Release 附带的 `.exe` 便携版后双击运行，放在任意位置即可，无需覆盖旧版本。

## 🔄 兼容性说明

- 已采集内容、既有项目与项目组不受影响，首次打开新版会自动完成一次本地数据升级（不会丢数据）。数据量大时首次打开可能稍慢几秒，属正常现象，之后即恢复秒开。
- 升级后请使用本版本或更新版本打开数据，不要再退回旧版本打开同一份数据。
- 错误记录只保存在本机浏览器本地，不写入项目数据，也不会上传或同步到其他电脑；导出诊断包由你手动发送。
