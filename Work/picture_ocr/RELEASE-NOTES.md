# 测评证据采集工具 v0.8.0

## ✨ 新增功能

- 项目管理中心新增「多系统项目」「独立系统」两个页签，项目组和独立系统分开展示，归属更清楚。
- 进入项目后只显示该项目的系统，可在项目内添加系统、管理项目信息和开启手机采集。
- 从采集工作区返回时，恢复之前的页签、项目、搜索条件和滚动位置；新建成功后自动定位到新增内容。

## 🛠️ 修复与优化

- 将编辑、导入导出、压缩图片和删除等操作统一收进「更多」，为系统名称和单位信息留出更多空间，并适配窄窗口。
- 切换页签、项目或搜索条件时清空批量选择，批量删除只处理当前可见的系统。
- 项目组即使只剩一个系统或暂时没有系统，也继续保留项目层级；项目组记录缺失时明确提示，关联的系统仍可打开和导出。
- 列表加载失败时提供重试入口，菜单支持键盘操作和根据窗口空间向上展开。

## 🔄 兼容性说明

- 网页版与 Windows 桌面版同步包含本次更新。
- 数据库版本、项目归属和图片存储格式保持不变，无需迁移数据；本次更新只调整项目管理界面及操作方式。
- 列表继续读取轻量摘要，分类和搜索不会加载整份项目文档或图片内容。

## 下载与使用

- Windows 桌面版：下载本 Release 的便携版 `.exe`。
- 网页版：下载 ZIP，解压后运行“启动测评证据采集工具.bat”，继续使用原来的浏览器和访问地址。
