# 测评证据采集工具 v0.7.3

## 修复与优化

- 修复异常项目文档被误记为图片迁移已完成的问题；历史上误记完成的已知异常记录可重新检查，正常项目仍继续处理。
- 修复图片对账将不存在或无效文档误报为一致的问题，无法检查时明确返回失败。
- 诊断包补充异常记录关联的独立图片条数和迁移状态；统计失败、缺少存储或状态无效时明确标记，不再将未知情况当作零张图片。
- 诊断导出使用只读数据库访问，不触发摘要修复、建库或数据库升级，也不读取图片字节。

## 兼容性说明

- 网页版与 Windows 桌面版同步包含本次修复。
- 数据库版本和项目、图片存储格式不变；不自动删除异常项目或图片，不用空项目覆盖原数据。
- 关联图片条数不代表图片有效或能够恢复。本版本改进异常判定与取证信息，不代表损坏内容已恢复。

## 下载与使用

- Windows 桌面版：下载本 Release 的便携版 `.exe`。
- 网页版：下载 ZIP，解压后运行“启动测评证据采集工具.bat”，继续使用原来的浏览器和访问地址。
- 已遇到数据缺失时，先正常退出软件，完整复制当前数据目录及仍存在的旧备份，再运行新版。软件已关闭时不要为查看路径反复启动，避免迁移旧备份到期后被自动清理。
