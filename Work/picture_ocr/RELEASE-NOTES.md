## ✨ 新增功能

- **左侧分类栏可以左右拖宽**：资产名带 IP（例如「服务器1 (192.168.1.10)」）以前会被截成省略号，不好截图。现在按住分类栏右边缘左右拖，就能把全名露出来；松开后会记住宽度，下次打开还在。平时没有额外的拖动手柄，只有靠近或拖动时才出现蓝线。

## 📦 下载与使用

- **Web 静态版**：下载本 Release 附带的 web ZIP，解压后双击“启动测评证据采集工具.bat”，运行期间保持 PowerShell 窗口开启。
- **Windows 客户端**：下载本 Release 附带的 `.exe` 便携版后双击运行，放在任意位置即可，无需覆盖旧版本。

## 🔄 兼容性说明

- 数据格式与存储位置不变，已采集内容、既有项目与项目组不受影响，无需迁移。
- 侧栏宽度只保存在本机浏览器本地，不写入项目数据，也不会同步到其他电脑。
