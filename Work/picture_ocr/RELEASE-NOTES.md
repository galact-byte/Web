# 测评证据采集工具 v0.8.6

- 修复小体积、高分辨率截图被缩小后文字变糊的问题。小于 1 MB（1024 KB）的图片保留原文件和分辨率，不再因长边超过 1920 像素而压缩。
- 手机拍摄的大照片继续按原规则压缩，控制大量照片带来的项目体积和 Word 报告导出负担。
- Web 版和 Windows 桌面版同步生效，覆盖粘贴、选文件、手机采集、数据包导入及手动图片压缩。Word 报告保留入库图片的完整分辨率。

已被压缩缩小的旧图片不会自动恢复；需要从原图重新添加。
