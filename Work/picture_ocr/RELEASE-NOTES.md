# 测评证据采集工具 v0.7.2

## 修复与优化

- 补充存储自检的异常记录详情：区分“读取成功但返回值无效”和“数据库读取请求失败”，便于排查系统记录无法显示的问题。
- 导出诊断包时，异常详情包含对应记录 ID、无效返回值的类型，或读取失败的错误名称与信息；不附带项目正文或图片内容。
- 保留现有存储自检提示和异常记录清单，单条记录读取失败不影响后续记录的检查。

## 兼容性说明

- 网页版与 Windows 桌面版共用本次改进。
- 本次不改变数据库版本或项目、图片的存储格式，不新增数据迁移，不自动删除或用空项目覆盖异常记录。
- 本次用于进一步定位读取失败原因，不代表已有异常记录能自动恢复。

## 下载与使用

- Windows 桌面版：下载本 Release 的便携版 `.exe` 后运行。
- 网页版：下载本 Release 的 ZIP，解压后运行“启动测评证据采集工具.bat”，继续使用原来的浏览器和访问地址。
- 遇到系统记录缺失时，请先备份原始数据目录，不要清理数据。使用本版本在“存储设置”中执行“存储自检并修复”，再导出诊断包以便排查。
