# 测评证据采集工具 v0.7.1

## 修复与优化

- 修复打开项目后返回项目列表时，右上角反复提示同一条「存储自检：已找回项目」的问题。同一份自检结果在当前页面会话内只提示一次，无需手动点击「存储自检并修复」来消除重复提示。
- 保留真正需要关注的通知：新一轮自检找回项目或发现无法读取的记录时，仍会正常提示；存储设置和诊断包中的自检结果继续保留。

## 兼容性说明

- 网页版与 Windows 桌面版共用本次修复。
- 本次仅调整提示去重，不改变项目和图片的存储格式，不新增数据迁移。已有项目、照片和 v0.7.0 的图片独立存储功能保持不变。

## 下载与使用

- Windows 桌面版：下载本 Release 的便携版 `.exe` 后运行。
- 网页版：下载本 Release 的 ZIP，解压后运行「启动测评证据采集工具.bat」，继续使用原来的浏览器和访问地址。
