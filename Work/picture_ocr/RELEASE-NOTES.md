## ✨ 新增功能

- **手机局域网采集升级为「项目组级」**：以前每切换一个系统就要重开局域网、手机重新扫码，非常繁琐。现在**一次启动、整组通用**——电脑端生成一个二维码，手机扫码后可在采集页**自由切换该项目组下的任意系统**逐个拍照取证，全程链接不断、无需重扫。
- **手机端新增「选择系统」**：进入拍照前先选目标系统，图片自动写入对应系统。若上传到电脑端**当前正在查看的系统**，工作台会**实时刷新**显示新到的截图与张数。
- **项目列表直接开采集**：在「项目管理中心」的项目组行或单系统行即可点「手机采集」启动整组会话，不必先进入某个系统；进入系统后工具栏仍显示「采集中」，可随时查看二维码或停止。

## 🛠️ 修复与优化

- **会话更稳**：在同一项目组内切换系统、返回项目列表都不再中断手机采集会话，链接持续有效。
- **上传更严谨**：每张图片按「系统 / 资产 / 检查项」三级归属校验，杜绝误传到别的系统；不属于本次会话的目标一律拒绝。
- **两种运行方式一致**：Web 静态版与 Windows 客户端在上述能力上行为完全一致。

## 📦 下载与使用

- **Web 静态版**：下载本 Release 附带的 web ZIP，解压后双击“启动测评证据采集工具.bat”，运行期间保持 PowerShell 窗口开启。
- **Windows 客户端**：下载本 Release 附带的 `.exe` 便携版后双击运行，放在任意位置即可，无需覆盖旧版本。

## 🔄 兼容性说明

- 数据格式与存储位置不变，已采集内容、既有项目与项目组不受影响，无需迁移。
- 只有一个系统的项目组保持原有体验：手机端自动选中该系统，无需手动切换。
- 本次升级了采集会话协议，请确保**电脑端程序与手机采集页使用同一版本**（重新扫码打开即为最新页面）。
