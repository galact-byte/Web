## 🛠️ 修复与优化

- **修复 Web 版偶发“项目数据消失”**：启动器改用固定端口。此前若上一个服务窗口没关，重新启动会更换端口；浏览器按“地址 + 端口”隔离本地存储，于是进入一个空列表——数据本身从未丢失，只是没在那个地址下。现在端口固定，数据始终可见；若检测到已有实例在运行，会直接打开现有页面。
- **修复桌面版更改数据存储位置后“点立即重启却不再打开”**：便携版运行在系统临时目录，旧的重启方式会失效；现改用真实便携程序重启。
- **移除 Web 导出的“询问保存位置”开关**：它与浏览器自带的“下载前询问保存位置”重复，还会出现提示叠加；导出统一交给浏览器下载。

## 📦 下载与使用

- **Web 静态版**：下载本 Release 附带的 web ZIP，解压后双击“启动测评证据采集工具.bat”，运行期间保持 PowerShell 窗口开启。
- **Windows 客户端**：下载本 Release 附带的 `.exe` 便携版后双击运行，放在任意位置即可，无需覆盖旧版本。
