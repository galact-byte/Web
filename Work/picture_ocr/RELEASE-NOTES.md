# 测评证据采集工具 v0.9.0

新增存储提醒和系统归档，用来把不常用系统的图片移出本机，腾出磁盘空间。

## 存储提醒

- 打开项目列表时自动检查以下三种情况，满足任一种就在列表顶部显示提示：本工具占用超过 2 GB、数据所在磁盘剩余不足 10 GB、有系统超过 90 天未修改。可以直接从提示进入归档。
- 选「稍后提醒」后 7 天内不再提示；磁盘剩余低于 3 GB 时仍会提示。
- 阈值可以在「存储设置」里修改。

## 存储设置

- 显示数据所在磁盘的剩余空间，以及浏览器是否已为本工具开启持久存储。开启后，磁盘紧张时浏览器不会自动清除数据。
- 新增按占用排序的系统清单，列出所属项目组、图片张数、占用大小和最后修改时间。

## 系统归档与恢复

- 在「存储设置」或提示里勾选要归档的系统（可多选），再选择保存目录，例如 D 盘或移动硬盘。每个系统生成一个 ZIP 文件。
- 写入后从磁盘读回文件，逐张核对图片。全部一致才删除本地图片；任何一步失败都保留本地数据，并说明原因。
- 归档后系统仍在列表中，标为「已归档」，并保留项目组和系统信息。已归档系统只读：不能打开编辑，也不会出现在手机采集的系统列表里。
- 点「恢复」并选择对应的归档文件，即可原样写回图片，不会重新压缩，Word 报告清晰度不变。文件不属于这个系统，或内容有损坏、被改动时，会拒绝恢复。
- 归档文件同时是标准数据包，可以用「导入数据包」导入到其他电脑。
- 网页版需要支持选择目录的 Chrome 或 Edge；其他浏览器不提供归档，不会改成下载到默认的 C 盘下载目录。

网页版请使用本版附带的启动脚本打开，才能显示磁盘剩余空间。
