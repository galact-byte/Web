# 测评证据采集工具 v0.8.3

- 修复后台暂停或网络中断后，电脑已保存照片但手机仍停在“尚未确认”的问题。恢复前台或网络后会自动核对；手机一直在前台时也会继续核对迟到的保存结果，自动核对不会重复上传照片。
- 修复手机采集页显示“未命名项目组”或旧名称的问题。从工作台或项目列表改名后，正在使用的采集会话会同步更新名称。
- 改善 Chrome 拍照入口：局域网 HTTP 等不支持网页相机的环境下，点击拍照直接调用系统相机入口，不再先尝试失败后要求再次选择回退。

网页版与 Windows 桌面版同步更新，无需迁移数据。更新电脑端后，重新开启手机采集并打开新的采集链接。

后台恢复已通过双端页面暂停和网络故障模拟验证，尚未进行真实 Windows 自动锁屏与手机原生相机实测。电脑睡眠、断网或浏览器被系统回收时无法保证继续传输；待处理原图只保留在当前手机页面，刷新或关闭前请先保存原图。
