# 测评证据采集工具 v0.8.2

## 🛠️ 修复与优化

- 修复手机拍照或相册上传长时间卡在“同步中”的问题。网页版局域网服务可独立处理多个连接，异常连接不再拖住其他上传与保存确认。
- 上传过程区分图片处理、上传和等待电脑保存。连接超时后可重新核对并重试，当前照片与原采集目标会保留，也可手动保存原图。
- 修复确认消息丢失后重试可能重复保存的问题；同一张待传照片重复核对或重试不会重复入库，也不会因切换系统而传错位置。
- 只有电脑实际保存完成才显示同步成功；结果暂时无法确认时明确提示，避免将迟到的保存误报为失败。
- 改善断连、保存失败和会话结束后的恢复操作，清理迟到请求与图片处理资源，防止旧会话结果干扰新会话。

## 🔄 兼容性说明

- 网页版与 Windows 桌面版同步更新，数据库版本与图片存储格式不变，无需迁移数据。
- 更新电脑端后，重新开启手机采集并打开新的采集链接，使两端使用同一版本。
- 待处理原图仅保留在当前手机页面，刷新、关闭页面或浏览器回收后无法恢复；离开前请先保存原图。

## 下载与使用

- Windows 桌面版：下载本 Release 的便携版 `.exe`。
- 网页版：下载 ZIP，解压后运行“启动测评证据采集工具.bat”，继续使用原来的浏览器和访问地址。
