## 要求

- R1：给出有代码与历史依据的调查结论，区分确定事实、推测和无法判断事项。
- R2：提供保全当前数据目录与迁移旧备份的步骤，避免启动清理旧备份；只在副本上取证，不要求用户操作开发者控制台。
- R3（已批准实施）：诊断能够只读报告异常主键关联的独立图片记录数量、迁移状态，以及统计失败/未知状态；数量不是可恢复性保证，不附带正文或图片字节。
- R4（已批准实施）：图片迁移不能将 null 文档计为正常完成；图片对账不能将不可读文档报告为一致。历史误记完成的异常 ID 必须可重新检查。
- R5（已批准实施）：上述公共数据库逻辑同时覆盖网页与桌面；失败不覆盖主文档、不删除图片、不伪造摘要。

## 验收条件

- AC1 / R1：调查记录给出版本演变、函数位置与本次诊断证据，明确尚未确定 null 的产生原因。
