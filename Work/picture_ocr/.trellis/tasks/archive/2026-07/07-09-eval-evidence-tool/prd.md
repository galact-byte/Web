# 测评证据采集工具

## Goal

为等保测评现场人员构建一个纯前端 Web 工具，支持按资产逐项截图录入测评证据，通过"导出数据包 → 他人导入"的方式分享，并能一键导出符合模板格式的 Word 报告。

## Background（背景与用户价值）

- 现场测评人员在测评过程中需要按资产逐项截图作为证据，目前缺少便捷的工具来管理这些截图
- 需要将收集的证据打包分享给内网其他同事（非实时协作，而是导出/导入方式）
- 最终需要一键生成符合《测评证据截图要求V1.0》模板格式的 Word 报告
- 采用纯前端方案，无需服务器/数据库/Node，双击即可使用，降低部署成本

## Confirmed Facts

- **部署方式**：Vite 打包为纯静态站点，可双击 index.html 使用，也可部署到 Nginx/IIS 静态目录
- **分类体系**：从 Word 模板提取的 7 大类 + 1 个"其他"分类 = 共 8 个分类
  - 物理环境、网络设备、安全设备、主机设备、系统管理软件、应用系统、管理层面、其他
- **管理层面**：保持自由材料列表形式，不搞资产化结构
- **多图排版（Word）**：一行 2 张图片并排排列
- **报告封面**：保留原模板样式（标题、单位名称、日期）
- **必填校验**：需要实现，导出 Word 时提示未完成的必填检查项
- **Word 模板结构**：
  - 封面页：标题"测评证据截图要求"、版本 V1.0、公司名称、日期
  - 一级标题 = 分类名称
  - 二级标题 = 资产名称（含 IP/地址信息）
  - 每个检查项 = 表格一行（左侧文字 + 右侧截图）
  - 多图按 2 张一行排列
  - "管理层面"特殊章节：按材料名称分组

## Requirements

### R1 分类/资产/检查项管理
- [x] R1.1 左侧栏展示 8 个分类（物理环境、网络设备、安全设备、主机设备、系统管理软件、应用系统、管理层面、其他）
- [x] R1.2 每个分类下可添加多个资产（如"核心交换机(192.168.1.1)"），可重命名/删除
- [x] R1.3 每个资产自动带出该分类的默认检查项列表
- [x] R1.4 每个资产可自定义增/删/改检查项（不影响模板默认项）
- [x] R1.5 "管理层面"分类以自由材料列表形式展示，按材料名称添加/管理

### R2 图片上传与管理
- [x] R2.1 每个检查项支持上传多张图片（粘贴 Ctrl+V / 拖拽 / 点击选择）
- [x] R2.2 图片缩略图展示，鼠标悬浮显示放大预览和删除按钮
- [x] R2.3 每张图片可添加简短备注文字
- [x] R2.4 未上传时显示占位提示区域

### R3 本地持久化
- [x] R3.1 所有数据自动保存到浏览器 IndexedDB，刷新不丢失
- [x] R3.2 图片二进制数据也存入 IndexedDB

### R4 数据包导入/导出
- [x] R4.1 导出为 .zip 包（manifest.json + images/ 目录）
- [x] R4.2 导入支持两种模式：覆盖导入（替换当前工作区）和合并导入（按资产 id 去重合并）
- [x] R4.3 使用 JSZip 在浏览器端完成打包/解包

### R5 Word 报告导出
- [x] R5.1 一键导出 .docx 文件，使用浏览器端 `docx` 库
- [x] R5.2 封面页保留模板格式（标题、单位名称、日期）
- [x] R5.3 一级标题 = 分类名称，二级标题 = 资产名称
- [x] R5.4 每个检查项渲染为表格行（左侧文字 + 右侧截图）
- [x] R5.5 多图按 2 张一行排列
- [x] R5.6 "管理层面"特殊处理

### R6 必填校验
- [x] R6.1 检查项可标记为必填（模板默认项自动为必填）
- [x] R6.2 导出 Word 时检查所有必填项是否有截图
- [x] R6.3 如有未完成的必填项，弹窗提示用户具体哪些检查项缺少截图
- [x] R6.4 用户可选择继续导出或返回补充

### R7 项目信息管理
- [x] R7.1 可编辑项目名称、被测单位名称、测评人员姓名
- [x] R7.2 报告日期自动生成（可手动调整）
- [x] R7.3 这些信息反映在 Word 报告封面上

### R8 模板管理
- [x] R8.1 可统一编辑每个分类的默认检查项模板
- [x] R8.2 模板修改影响后续新建的资产，不影响已有资产

- [x] AC3: 支持 Ctrl+V 粘贴截图、拖拽上传、点击选择文件
- [x] AC4: 多图支持：上传、缩略图、预览、删除、备注
- [x] AC5: 刷新页面后所有数据保留（IndexedDB）

- [x] AC7: 合并导入模式正确处理去重
- [x] AC8: 一键导出 Word 报告，格式符合模板要求
- [x] AC9: 多图在 Word 中按 2 张一行排列
- [x] AC10: 必填项缺失时导出时弹出提示
- [x] AC11: 项目信息修改后正确反映在封面上

## Out of Scope

- 多人实时协作编辑（当前采用"导出导入"方式）
- 后端服务器/数据库/用户认证系统
- 移动端 APP 或小程序
- Word 模板的自定义编辑功能（模板固定）
- 图片的云端存储/备份
