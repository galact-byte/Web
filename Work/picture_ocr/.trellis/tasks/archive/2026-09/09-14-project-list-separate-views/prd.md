# 项目组与独立系统分开展示

## 目标与授权

用户反馈项目管理中心将多系统项目与单系统混排，层级难以辨认。本任务让用户快速定位项目或独立系统，减少列表中同时出现的信息与操作。

用户已批准创建任务与规划，并在评审后回复「可以，请继续吧」批准实施；任务已激活。完成验证后，用户进一步批准提交、推送并发布 Release。

## 已确认需求

### R1 分类与可见性

- 项目管理中心提供「多系统项目」「独立系统」两个页签，并显示准确数量。
- 按项目组归属分类；有归属的项目组即使只有一个或零个系统，也保留在多系统项目中。
- 多系统项目顶层仅显示项目组；进入后只显示该组系统，并有明确项目标题和返回入口。
- 无归属系统出现在独立系统页签，直接打开采集工作区。
- 组记录缺失但仍有关联系统时，在多系统项目中标明「项目组记录缺失」，保留系统的打开与导出能力；不隐藏、不自动移组或删除。

### R2 操作层级

- 项目组列表保留进入项目、手机采集与更多；项目内提供添加系统与项目管理操作。
- 系统列表常驻打开、手机采集与更多；窄屏可将手机采集收进更多，保证操作可达且不溢出。低频的编辑、导入数据包、导出数据包、压缩图片、删除统一收进更多菜单。
- 手机采集入口仍按环境能力显示，传入的系统范围与操作所在层级一致。
- 删除和压缩继续二次确认，执行状态与错误明确反馈，菜单支持键盘、Escape 和焦点恢复。

### R3 搜索、选择与返回

- 搜索限定当前页签或当前项目。项目列表可按项目字段或组内系统名找到所属项目；系统列表只显示匹配系统。
- 切换页签、进出项目或改变搜索时清空批量选择；批量操作只处理当前可见系统，不影响隐藏结果。
- 项目组顶层不提供跨组批量删除系统；保留独立系统列表和项目内的系统批量删除，以及单个项目组删除。
- 从工作区返回后恢复所在页签、项目、搜索条件和滚动位置；删除后定位到仍有效的列表，不能残留已删项目或选择。
- 首次默认多系统项目；只有独立系统时默认独立系统。空库、空项目与无搜索结果有各自提示。

### R4 新建与兼容

- 保留统一「新建项目」及当前单个/多个名称的创建规则，成功后定位到实际创建结果所在视图，让新增内容立即可见。
- 网页端与桌面端同步覆盖；保留手机专用页面、现有数据格式和工作区 URL 的兼容性。
- 列表继续读取轻量摘要，不读取图片字节或整份文档来分类、搜索、计数。
