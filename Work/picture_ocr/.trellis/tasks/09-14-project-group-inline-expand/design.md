# 技术设计（已确认）

## 边界与复用

主要修改 `ProjectList.tsx`、`project-list/projectListViews.ts` 和 `App.tsx` 的 UI 状态。以 `18c7fde` 的列表内展开为交互参考，复用当前轻量分类、共享系统网格、ProjectActions、确认框及存储 API；不整段回退旧版代码，不恢复混排或按系统数量隐藏组的逻辑。现有去除重复分类标题的一行修改保留。

## 展示与状态

- `ProjectListLocation` 收敛为 groups / independent；移除组详情分支、进入项目与返回项目管理按钮。
- `ProjectListViewState` 继续由 App 持有，每个页签保存搜索/scrollY；增加普通展开 ID 和搜索期间展开 ID。使用 null 表示尚未初始化，空数组表示用户全部收起，不能混淆。
- 首次摘要成功加载时初始化所有真实/异常组为展开；后续加载只剔除已失效 ID，不因集合为空再次全展开。创建/添加显式展开目标。
- 搜索值改变时重新派生命中项目和可见子系统，初始化本次搜索展开 ID；搜索期间用户可覆盖展开状态。清除搜索丢弃搜索展开覆盖，恢复普通展开集合。两套状态随 App 保留，工作区返回不丢失。
- 仅依据成功加载的摘要修剪状态；失败保留上次状态。变更 props 使用函数更新，避免把展开字段在 navigate 中遗漏。
- 恢复滚动在列表和展开内容渲染后进行；创建定位使用一次性目标 ID，在刷新成功且目标存在后 scrollIntoView 并清除，不在普通 render 时持续抢滚动或焦点。

## 搜索和选择

纯 helper 返回匹配的项目及该项目应显示的系统，复用 filterSystems 和现有字段规则。项目字段命中显示全组；否则仅显示匹配的子系统。计数继续表示实际系统数，可另说明当前匹配数，不能把搜索数量当作项目总数。

选择继续是瞬时状态，增加当前选择所属组 ID。组内全选/删除工具放在该组展开区，调用共享 handler 并显式传入该组可见系统。切换选择组清空前组；收起组、切页或搜索清空选择。删除前求所属组可见系统与 selectedIds 交集。独立页保留现有工具栏。

系统行渲染提取或复用同一函数，传入所属摘要，避免原来 `activeGroup` 移除后编辑/导入/操作仍错误引用全局当前组。组级采集始终从未裁剪的 summary.systems 取 ID。

## 结构与无障碍

项目以浅色标题栏和独立容器区分，标题按钮包含 44×44px 展开区域、20px SVG 箭头和项目名，使用 aria-expanded/aria-controls，原生 Enter/Space 激活。单位、系统总数及更新时间集中在标题栏；工具放在展开按钮外。系统区使用自己的表头，复用 GROUP_SYSTEM_LIST_GRID 对齐名称、更新时间、资产数和操作，不复用项目字段表头；单位相同时省略重复，不同时在系统名下保留。全选位于表头，批量删除仅选择后显示，取消单独的组内工具栏。375px 保留可读名称与换行工具；收起时焦点回到项目按钮。

继续使用 ProjectActions 和共享网格；不新增依赖或全局样式。页签下分类标题仅保留必要的无障碍语义，移除重复可见文案和占位间距。

## 兼容、风险与取舍

- UI 状态不持久化到库，无跨版本数据迁移；工作区 hash 不变。
- 首次全展开复用旧版习惯；全展开只读取摘要、不预读图片。无需新增全部展开/收起工具。
- 当前新增/导入/删除等异步路径依赖刷新顺序，需区分保存失败和保存成功但列表刷新失败，不能误报保存未成功导致重复创建。
- 既有测试依赖详情层级，更新为等价展开行为断言，保留存储/采集/错误/菜单覆盖。
- 不修改跨窗口自动保存冲突；外部删除夹具继续使用另一系统工作区，验证列表刷新和落点。
