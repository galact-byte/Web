# DocGenPro

基于模板的 Word 文档批量生成工具，提供图形化界面，适用于等保测评授权文档等标准化文档的快速生成。

## ✨ 功能

- **图形化界面** - 填写表单即可使用，无需命令行操作
- **模板驱动** - 支持 `.docx` 模板与对应的填充规则
- **表格支持** - 自动处理文档中的表格内容填充
- **批量生成** - 一次填写信息，批量输出多份文档

## 📦 安装

支持 Windows x64，下载安装后即可使用，无需配置运行环境。

1. 打开 [DocGenPro 下载页面](https://github.com/galact-byte/Web/releases/tag/docgen-v2.1.0)。
2. 在页面底部 **Assets** 下载 `.exe` 安装程序，双击后按提示完成安装。
3. 从开始菜单或桌面快捷方式启动 **DocGenPro**。

安装包未签名，Windows 可能显示未知发布者提醒，请确认下载来源后再运行。

## 使用

- **单项目生成**：填写项目及系统信息，生成对应的 Word 文档。
- **多项目生成**：维护多个项目后批量生成文档，每个项目可分别选择验证测试方式。
- **验证测试方式**：在“执行验证测试（漏扫、渗透）”和“自愿放弃验证测试”中二选一。前者生成《验证测试授权书》，后者显示业务详情并生成《自愿放弃验证测试声明》；其余三份内置文档照常生成。默认选择自愿放弃，切换选项会保留已填写的业务详情。
- **重复生成**：切换验证测试方式后重新生成，原来与当前选择冲突的文档会移入输出目录内的“历史文档”文件夹保存。
- **模板管理**：查看和管理 Word 模板及填充规则。
- **设置**：配置测评机构、联系人等常用信息。
