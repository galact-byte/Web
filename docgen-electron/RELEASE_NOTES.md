# DocGenPro 2.1.0

这次更新提供 Windows 安装包，并整理项目管理、历史记录和外观设置的使用体验。

## 新增

- **Windows x64 安装包**：下载并运行 `.exe` 安装程序即可安装。文档生成程序、内置模板和规则均已包含，无需配置运行环境。
- **四级系统选项**：单项目和多项目表单均可选择四级系统。

## 修复与优化

- **修复中文输出导致的启动失败**：文档生成程序统一使用 UTF-8 输出，避免在英文 Windows 环境或输出被重定向时因中文日志崩溃。
- **历史记录分开管理**：区分单项目与多项目历史；保存单项目历史时保留已有的多项目记录，避免两种模式相互干扰。
- **项目操作更清晰**：重新整理单项目表单、多项目列表及操作区；多项目历史支持删除单条记录或清空该模式的历史。
- **统一页面布局**：调整导航、模板资源、联系信息和外观设置页面的排版，统一按钮、表格和弹窗样式。
- **外观设置集中管理**：统一处理主题色、浅色/深色模式、字体、动画和背景设置。
- **模板列表更准确**：仅列出文件，不再将子目录当作模板或规则显示。

## 安装与兼容性

- 适用于 **Windows x64**，不提供 macOS、Linux 或 Windows ARM64 原生安装包。
- 安装程序尚未签名，Windows 可能提示未知发布者，请确认下载来源后再运行。
- 当前不支持应用内自动更新，更新时需手动下载安装包。
- 本次未修改内置 Word 模板及填充规则。若使用了自定义模板或规则，请在重新安装前备份，避免被安装包内的同名文件替换。
